# Blogicum

Blogicum — учебная социальная сеть для публикации записей, комментирования и взаимодействия пользователей.

Проект разработан на Django в рамках обучения backend-разработке. Приложение позволяет пользователям создавать и редактировать публикации, добавлять изображения и комментарии, просматривать профили авторов и публикации по категориям.

## Возможности

* регистрация и авторизация пользователей;
* просмотр профилей пользователей и их публикаций;
* создание, редактирование и удаление публикаций;
* отложенная публикация записей;
* добавление изображений к публикациям;
* разделение публикаций по категориям;
* привязка публикаций к местоположению;
* создание, редактирование и удаление комментариев;
* разграничение прав доступа к публикациям и комментариям;
* пагинация списков публикаций;
* Django Admin для управления данными;
* автоматическое тестирование проекта.

## Модели

Основная логика приложения построена вокруг следующих сущностей.

### Post

Публикация пользователя. Содержит:

* заголовок;
* текст;
* дату публикации;
* автора;
* категорию;
* местоположение;
* изображение;
* статус публикации.

Предусмотрена возможность отложенной публикации: если дата публикации находится в будущем, запись не отображается другим пользователям до наступления указанного времени.

### Category

Категория публикации с названием, описанием и уникальным `slug`.

### Location

Местоположение, связанное с публикацией.

### Comment

Комментарий к публикации с указанием автора и даты создания.

## Работа с публикациями

Авторизованный пользователь может создать публикацию. Автор автоматически устанавливается текущим пользователем.

Редактировать и удалять публикацию может только её автор.

Для отображения публикаций используется общая логика выборки, которая:

* скрывает неопубликованные записи;
* не показывает записи с будущей датой публикации;
* учитывает статус категории;
* использует `select_related()` для связанных объектов;
* подсчитывает количество комментариев через `annotate()` и `Count()`;
* поддерживает пагинацию.

## Работа с комментариями

Авторизованные пользователи могут оставлять комментарии к публикациям.

Автор комментария может:

* редактировать свой комментарий;
* удалять свой комментарий.

Пользователь не может изменять или удалять комментарии других авторов.

## Права доступа

В проекте реализовано разграничение доступа на уровне представлений Django:

* создавать публикации и комментарии могут только авторизованные пользователи;
* редактировать и удалять публикации может только их автор;
* редактировать и удалять комментарий может только его автор;
* пользователь может редактировать собственный профиль.

## Оптимизация запросов

Для уменьшения количества запросов к базе данных используются возможности Django ORM.

В частности:

* `select_related()` применяется для связанных объектов `author`, `category` и `location`;
* `annotate()` и `Count()` используются для подсчёта комментариев;
* отдельная функция формирования QuerySet используется для централизованной фильтрации и подготовки публикаций.

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Galeopik/Blogicum.git
cd Blogicum
```

### 2. Создать виртуальное окружение

Windows:

```bash
python -m venv venv
```

Linux / macOS:

```bash
python3 -m venv venv
```

### 3. Активировать виртуальное окружение

Windows:

```bash
venv\Scripts\activate
```

Linux / macOS:

```bash
source venv/bin/activate
```

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

### 5. Выполнить миграции

Перейдите в директорию с `manage.py`:

```bash
cd blogicum
```

Затем выполните:

```bash
python manage.py migrate
```

### 6. Запустить сервер

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000/
```

## Административная панель

Для управления пользователями, публикациями, категориями, местоположениями и комментариями используется стандартная административная панель Django.

Создание суперпользователя:

```bash
python manage.py createsuperuser
```

После этого административная панель доступна по адресу:

```text
http://127.0.0.1:8000/admin/
```

## Загрузка тестовых данных

В репозитории присутствует файл `db.json` с данными для разработки.

При необходимости данные можно загрузить с помощью:

```bash
python manage.py loaddata ../db.json
```

Команду необходимо выполнять из директории, содержащей `manage.py`.
